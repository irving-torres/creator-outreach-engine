# Pitch Framework

Voice rules for every outbound draft.

- Warm and human, never templated-sounding. Write like a person, not a media kit.
- Conversational and specific: name the actual reason the brand fits this audience.
- Short. Respect the reader's time.
- No price in the outbound message. Introduce the rate only if the brand replies.
- Never explain rate reasoning or leak enthusiasm.
- No em dashes. Commas and periods.
- Proof first: lead with evidence (views, engagement, past partnerships), not adjectives.
- One clear, low-pressure call to action.
